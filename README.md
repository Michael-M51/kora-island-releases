# Kora Island releases

Windows installers for [Kora Island](https://kora.science/island/), a Dynamic Island–style bar for Windows 11 with on-device dictation (Kora Voice).

**[Download the latest installer](https://github.com/Michael-M51/kora-island-releases/releases/latest/download/KoraIsland-Setup.exe)** · [All releases](https://github.com/Michael-M51/kora-island-releases/releases)

- Windows 11 x64
- Installs for your account only, no admin prompt
- Kora Voice is included

The installer isn't code-signed yet, so Windows SmartScreen will warn you. Choose **More info**, then **Run anyway**.

This repo only hosts release files. Privacy details and third-party notices are on [kora.science/island](https://kora.science/island/).
